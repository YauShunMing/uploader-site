Privacy policy

Last updated: 27 September 2026

civuploader is a private tool used only by its owner to manage the owner's own YouTube channels.

What it accesses

With the owner's permission, it uses YouTube API Services to upload videos, set thumbnails, add captions and read basic information about the owner's own channels and videos.

What it stores

OAuth refresh tokens are kept only on the owner's own computer. No data about other people is collected, sold or shared.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
